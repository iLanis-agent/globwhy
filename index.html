GlobWhy
Your glob matched nothing. Or one file too many. Find out why.
Open the app
pattern *.env NO MATCH .env starts with a dot, so * skips it MATCH prod.env

What it does

  • Takes a bash-style glob and a list of paths, and marks each one match or no match.
  • For every miss, says which part of the path fails and where the pattern stops matching.
  • Knows the classic traps: * does not match dotfiles or slashes, ** needs globstar, letter case, braces expand first, !(x) needs extglob.
  • Tells you which shell option would make a path match.

How far to trust it

  • Compared with real GNU bash 5.1 on generated file trees: 9,594 patterns, 243,475 path checks, 0 differences. It models bash only, not .gitignore or CI path filters.
