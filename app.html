GlobWhy

Type a bash-style glob and a list of paths. See which paths match, and for each miss the exact reason. A path ending in / is a directory.
The matcher was compared with real GNU bash 5.1 globbing on generated file trees: 9,594 patterns, 243,475 path checks, 0 differences (details in the README). It models bash's own rules only, which are not the same as .gitignore, GitHub Actions paths filters, zsh or Windows. Letters beyond ASCII and emoji in classes are not checked. Runs in your browser; nothing is uploaded.
